## 1. Hello World для интерфейса (до 18.10)

**Цель:** страница на React + TypeScript, которая запрашивает ответ у API и показывает его. Так мы проверяем, что интерфейс и сервер вообще соединяются.

**Что понадобится:** Node.js (версия LTS) с сайта nodejs.org.

**Как сделать:**

1. Создай ветку:
```
git checkout develop
git pull
git checkout -b feature/web-hello-world
```
2. Перейди в папку `web` и создай проект:
```
cd web
npm create vite@latest . -- --template react-ts
```
Если спросит про непустую папку, выбери **Ignore files and continue**.
3. Установи пакеты и запусти:
```
npm install
npm run dev
```
Открой адрес из терминала (обычно `http://localhost:5173`). Должна открыться стартовая страница.
4. Открой файл `src/App.tsx`, удали всё и вставь:
```tsx
import { useEffect, useState } from "react";

const API_URL = "http://localhost:5000"; // точный адрес API уточни у Илоки

export default function App() {
  const [message, setMessage] = useState("Загрузка...");

  useEffect(() => {
    fetch(`${API_URL}/api/hello`)
      .then((r) => r.json())
      .then((data) => setMessage(data.message))
      .catch(() => setMessage("API пока недоступен"));
  }, []);

  return (
    <div style={{ padding: 24 }}>
      <h1>Lectnote</h1>
      <p>{message}</p>
    </div>
  );
}
```
Илока сделает адрес `/api/hello` к 18.10. Пока его нет, страница покажет «API пока недоступен», и для проверки это нормально.
5. Создай файл `web/Dockerfile`:
```
FROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
```
6. Отправь работу (команды из `git-guide.md`) и открой pull request в `develop`.

**Результат:** страница открывается в браузере, `Dockerfile` лежит в `web/`, pull request создан.

## 2. Макеты в Figma (до 19.10)

**Что понадобится:** бесплатный аккаунт на figma.com.

**Как сделать:**

1. Создай файл с названием «Lectnote».
2. Нарисуй по одному экрану (кадр создаётся клавишей **F**):
   1. Вход и регистрация
   2. Список лекций (предметы и лекции группы)
   3. Редактор заметки с блоками текста
   4. Загрузка аудио (выбор файла и статус расшифровки: ожидание, готово, ошибка)
   5. Комментарии к блоку
   6. Уведомления
3. Не старайся нарисовать идеально. Сначала простые прямоугольники и текст, потом аккуратность. Используй один шрифт и 2–3 цвета.
4. Старые и неудачные варианты не удаляй, а перенеси на отдельную страницу «Архив».
5. Нажми **Share**, выбери доступ **Anyone with the link can view** и скопируй ссылку.
6. Вставь ссылку в файл `docs/README.md` (если его нет, создай) и отправь pull request в `develop`. Ветка: `feature/figma-link`.

**Результат:** ссылка на Figma лежит в `docs/README.md`, на макетах есть все 6 экранов.

## 3. Проверка (21–22.10)

Проверь части других участников по списку:

- в репозитории нет паролей и лишних файлов (`.env` не добавлен).

## Если что-то не получается

Скопируй текст ошибки из терминала и отправь в чат команды. Одной строки «не работает» недостаточно, нужен сам текст или скриншот.
